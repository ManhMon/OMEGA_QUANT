P2 (per-ticker turnover):
  Implementation at compute_metrics (tickers != None branch):
    valid_sorted = valid.sort_values(["ticker", "date"])
    per_ticker_turn = valid_sorted.groupby("ticker")["pos"].diff().abs()
    turnover = float(per_ticker_turn.mean())
  ✓ Sorts (ticker, date) → groupby ticker → diff pos → abs → mean.
  ✓ Mathematically correct: each ticker's |Δposition| over time, averaged
    across all ticker-day observations. Preserves per-ticker signal change
    info that was destroyed by old portfolio-mean-then-diff approach.
  ✓ NaN at the first date per ticker is correctly excluded by .mean()
    (pandas mean ignores NaN).

P3 (sign-balance guard):
  Implementation at run_walk_forward inner loop:
    demean_alpha = alpha - np.median(alpha)
    nz = demean_alpha[demean_alpha != 0]
    if len(nz) >= 10:
        sign_balance = float(np.mean(np.sign(nz) > 0))
        if abs(sign_balance - 0.5) > 0.4:
            skip
  ✓ Threshold 0.4 → rejects alphas where >90% (or <10%) of post-demean
    values share one sign. Reasonable: leaves room for legitimate skewed
    signals while catching mono-sign collapse (e.g., vol_ratio - 0.999).
  ✓ Guards on len(nz) >= 10 to avoid spurious rejection on tiny samples.
  ✓ Sits AFTER std<1e-6 constant-alpha filter → defense in depth.

Backward compatibility:
  ✓ Function signature: compute_metrics(..., tickers=None) preserves default.
  ✓ Else-branch still computes old portfolio-mean turnover.
  ✓ All in-file callers updated to pass tickers=pd.Series(test_tickers),
    so the corrected path is exercised in production.
