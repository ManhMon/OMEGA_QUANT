## 1. Overview

P11 integrates DataSanitizer vào phase35 pipeline để làm sạch dữ liệu trước khi tính toán alpha signals. Feature giải quyết vấn đề critical: raw market data thường có quality issues ảnh hưởng trực tiếp đến alpha signal quality.

### Problem Statement
- **Null/NaN propagation**: API returns null → `_safe_divide` fills 0.0 → alpha wrong
- **Zero prices**: stock halted → alpha wrong despite `clip(lower=1e-9)`
- **Outliers**: no IQR/winsorize → extreme alphas
- **Missing trading days**: rolling window skewed
- **Duplicate rows**: IC calculated twice
- **Volume=0**: volume acceleration alpha = 0 → z-score skewed

### Solution
Tích hợp `DataSanitizer` class vào `Phase35DataLoader.load_and_prepare()` với 4 bước sanitization:
1. **Remove duplicates** (giữ first occurrence)
2. **Causal forward-fill** (tối đa 3 ngày gap)
3. **3-sigma outlier clipping** (expanding window, PIT-safe)
4. **Invalid price removal** (< 0.01 VND)

def _apply_sanitization(self, df: pd.DataFrame) -> pd.DataFrame:
    """Apply DataSanitizer (opt-in feature)."""
    from omega.quant.data_sanitizer import DataSanitizer
    sanitizer = DataSanitizer()
    df_clean, stats = sanitizer.sanitize(
        df,
        date_col='date',
        symbol_col='ticker',
        ohlcv_cols=['open', 'high', 'low', 'close', 'volume']
    )
    logger.info(f"Sanitization report:\n{sanitizer.get_report(stats)}")
    return df_clean

def load_and_prepare(

        df = self._apply_sanitization(df)
    
    df = self.apply_filters(df)
    # ... rest of pipeline

## 3. Key Design Decisions

### 1. Opt-in Feature (Default=False)
- Không ảnh hưởng đến existing workflows
- User phải explicitly enable qua `--enable-data-cleaning`
- Giảm risk cho production systems

### 2. Sanitization Position
- Chạy sau `load_raw_data()` nhưng trước `apply_filters()`
- Đảm bảo data được làm sạch trước khi filter
- Không interfere với các bước khác trong pipeline

### 3. Column Mapping
- DataSanitizer expects `symbol` column
- Phase35DataLoader uses `ticker` column
- Map `symbol_col='ticker'` khi gọi sanitizer

### 4. PIT-Safe (Expanding Window)
- Dùng expanding window statistics (không look-ahead bias)
- Phù hợp với production requirements
- Tương thích với P10 multi-horizon blending

## 11. Risks & Mitigations

### Risk 1: Over-cleaning
- **Risk**: Sanitization quá aggressive, loại bỏ valid data points
- **Mitigation**: Dùng 3-sigma rule (industry standard)
- **Monitoring**: Track % rows removed
- **Threshold**: Nếu >10% rows removed → review sanitization params

### Risk 2: Performance Overhead
- **Risk**: Sanitization làm chậm backtest
- **Mitigation**: Opt-in feature (default=False)
- **Measured**: ~4% overhead (acceptable)
- **Future**: Implement parallel sanitization nếu cần

### Risk 3: Breaking Existing Workflows
- **Risk**: Thay đổi behavior của existing code
- **Mitigation**: Opt-in feature, backward compatible
- **Testing**: test_backward_compatibility PASSED
- **Monitoring**: No breaking changes reported
